# 陶瓷碎片修复工作台（Ceramic Shard Restoration Workbench）

供文物修复工作室整理、比对、拼接陶瓷碎片的本地离线 Web 应用。
所有图像分析均在本机用 OpenCV/NumPy 完成，**不访问任何外部服务**。

## 功能

- **批量上传**：一次选择多张带标尺的碎片正反面照片（JPEG/PNG），自动去背景分割、
  提取等弧长轮廓（400 点）与边缘 Lab 色带，生成透明抠图与缩略图。
- **标尺校准**：在图上点出标尺两端并输入实际长度（mm），全流程尺寸按毫米计算。
- **去背景 / 修轮廓**：可框选区域重新分割，也可沿边缘描绘多边形手工修正轮廓。
- **厚度录入**：每件碎片记录厚度数值与测量说明。
- **候选拼接**：对项目内碎片两两做本地分析，依据
  边缘曲率窗口相关、接缝刚性配准 RMSE、接触弧长度、邻接色带 ΔE、厚度差
  给出 0–100 评分与逐条评分依据。
- **无限画布**：平移/缩放，碎片拖拽、键盘旋转（R/L，Shift 每步 15°）、
  翻面（F）、收库/上台（Delete），已接受候选可一键吸附摆放。
- **候选裁定**：每条候选可标为**接受 / 待定 / 排除**；同一碎片同一段边缘被
  多条接缝占用时立即弹出矛盾提示，并检测三角形环的旋转角不闭合。
- **复原方案**：可另存多个方案、复制方案，分别保存布局与裁定结果，
  支持撤销/重做。
- **方案比较指标**：已上台数量、凸包覆盖率、碎片面积、复原外轮廓面积、
  未归位边缘长度与占比。
- **导出可打印复原图**：PNG，含碎片编号、已接受接缝及置信度、比例尺、
  项目/方案名与时间，并自动打开打印窗口。

## 运行

需要 Python 3.10+（离线环境请提前准备以下 wheel）：

```bash
pip install -r requirements.txt      # flask, opencv-python-headless, numpy, pillow
./run.sh                             # 或：python3 backend/app.py
```

然后在本机浏览器打开 **http://127.0.0.1:8000** 。
服务只监听 127.0.0.1，不对外暴露。

## 目录结构

```
backend/
  app.py        Flask 路由（项目/碎片/校准/匹配/方案/指标/导出辅助）
  database.py   SQLite 表结构（data/app.db）
  vision.py     OpenCV：上传压缩、去背景、轮廓、色带、抠图/缩略图
  matcher.py    曲率窗口 NCC、Kabsch 刚性配准、接缝延伸验证、评分
  metrics.py    覆盖率/未归位边缘、候选矛盾检测
static/
  index.html, css/style.css, js/{api,editor,app}.js   原生前端 + Canvas
data/
  app.db        SQLite（首次运行自动创建）
  images/       原图、透明抠图、缩略图（全部本地文件）
```

## 典型工作流

1. 首页「新建修复项目」。
2. 左栏选择正面/反面与编号前缀，批量上传照片。
3. 在碎片清单选中一件 → 右侧「校准尺寸 / 去背景 / 修轮廓」：
   先做标尺校准（黄色两点），必要时裁剪重分割或描点修轮廓，
   再填写厚度。所有碎片都校准后匹配结果才含毫米尺度依据。
4. 顶部「计算候选拼接」，右侧候选页查看评分依据，
   接受可信候选、排除明显错误的候选。
5. 在画布上摆放碎片：可选中候选后点「按候选吸附」，也可手工拖拽/旋转/翻面。
   裁定互相矛盾时画布顶部立即红字提示。
6. 用「另存方案」保留不同拼法；在「方案指标」页比较覆盖率与未归位边缘。
7. 「导出复原图」得到带编号、接缝置信度和比例尺的可打印 PNG。

## 说明与限制

- 候选评分是**辅助排序**，不替代修复人员判断；断裂面磨损、直边较多的碎片
  可能产生偶然高分候选，须结合色带、厚度与实物复核。
- 正反面照片目前各取已上传面做分割；匹配默认同面轮廓，需要正反面拼合时
  候选会给出“需要翻面”的提示。
- 单批匹配为两两本地计算，约 1–2 秒/对，碎片较多时请耐心等待。
